# مالية العائلة — Family Finance

تطبيق ويب عربي (RTL) لإدارة مال الأسرة: حسابات، دخل، مصروفات، تحويلات، ذهب، ديون، التزامات ثابتة، صدقات، تقارير.
قاعدة بيانات سحابية (Supabase) + مزامنة لحظية بين هاتفك وهاتف زوجتك + PWA يُثبَّت على الشاشة الرئيسية.

## النشر (حوالي 15 دقيقة، مجاني)

### 1) قاعدة البيانات (Supabase)
1. أنشئ مشروعاً على https://supabase.com (مجاني).
2. من **SQL Editor** الصق محتوى `supabase/schema.sql` كاملاً ثم **Run**.
3. من **Authentication → Providers → Email**: للتبسيط عطّل «Confirm email» (أو اتركه وأكّد بريدكما).
4. من **Project Settings → API** انسخ: `Project URL` و `anon public key`.

> لا تستخدم مفتاح `service_role` في التطبيق إطلاقاً. مفتاح `anon` آمن لأن كل الجداول محمية بـ Row Level Security.

### 2) الاستضافة (Vercel أو Netlify)
1. ارفع هذا المجلد إلى مستودع GitHub.
2. في Vercel: **New Project** ← اختر المستودع (Framework: Vite).
3. أضف متغيرين في Environment Variables:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Deploy. (Netlify: Build `npm run build`، Publish `dist`، والمتغيران نفسهما.)
5. في Supabase → **Authentication → URL Configuration** ضع رابط موقعك في Site URL.

### 3) أول استخدام
1. افتح الموقع ← أنشئ حساباً ← **إنشاء مساحة العائلة** (اختر دورك).
2. من **الإعدادات ← إنشاء رابط دعوة** وأرسله لزوجتك؛ تفتحه وتنشئ حسابها وتنضم تلقائياً.
3. أضف الحسابات وأرصدتها الافتتاحية، ثم ابدأ بتسجيل العمليات.
4. للتجربة: **الإعدادات ← تحميل بيانات تجريبية**، وبعدها **حذف البيانات التجريبية** قبل الاستخدام الفعلي.
5. على الآيفون: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية». على أندرويد: Chrome ← «تثبيت التطبيق».

### للتطوير محلياً
```
cp .env.example .env     # ضع القيم
npm install
npm run dev
```

## كيف تُحسب الأرقام (القواعد المالية)

| نوع الحركة | أثرها على الحساب | تدخل في الدخل/المصروف؟ |
|---|---|---|
| دخل `income` | يزيد | نعم (دخل) |
| مصروف `expense` | ينقص | نعم (مصروف) |
| تحويل `transfer` | ينقص حساباً ويزيد آخر | لا |
| قرض مستلم / ممنوح | يزيد / ينقص | لا |
| سداد دين / تحصيل دين | ينقص / يزيد | لا |
| تسوية يدوية (سبب إلزامي) | زيادة أو نقص | لا |

- **رصيد الحساب** = الرصيد الافتتاحي + الداخل − الخارج، ويُحسب دائماً من الحركات (لا رقم مخزّن قابل للانحراف). يوجد أيضاً View في القاعدة `account_balances` للمطابقة.
- **صافي الثروة** = الأرصدة + قيمة الذهب (الوزن × سعر الغرام الذي تحدده يدوياً) + المتبقي من ديون لنا − المتبقي من ديون علينا.
- **المتبقي من الدين** = الأصل − مجموع الدفعات.
- الالتزامات المتكررة **لا تُسجَّل تلقائياً**؛ تضغط «تأكيد الدفع» فتُنشأ حركة مصروف ويتقدّم تاريخ الاستحقاق.
- «**من قام بالمصروف/منسوب إليه**» (`owner`) منفصل عن «**من أدخلها**» (`created_by`)، ومنفصل أيضاً عن «**المستفيد**».

## المزامنة والأمان
- Supabase Realtime: أي إضافة تظهر عند الطرف الآخر خلال ثوانٍ.
- دون إنترنت: تُحفظ العملية على الجهاز بمعرّف فريد وتظهر بشارة «بانتظار المزامنة»، وتُرسل عند عودة الاتصال، ولا تتكرر لو أُعيد إرسالها (`UNIQUE(client_id)`).
- RLS على كل الجداول: لا يصل للبيانات إلا عضوا العائلة. الانضمام بدعوة لمرة واحدة وبحد أقصى عضوين.
- الحركات لا تُحذف نهائياً (حذف ناعم) وكل إضافة/تعديل/حذف مسجّل في `audit_log` (يظهر في الإعدادات).

## بنية المشروع
```
supabase/schema.sql      الجداول والـ Views وRLS والمشغّلات والدوال
src/lib/finance.js       كل المعادلات المالية (مكان واحد للتدقيق)
src/lib/store.jsx        تحميل البيانات + Realtime + طابور العمل دون اتصال
src/pages/*              صفحات التطبيق
src/components/*         النماذج والمكونات
public/sw.js             PWA
```

## ما أُضيف فوق المطلوب
تنبيهات ذكية في الرئيسية (استحقاقات، ميزانيات، رصيد سالب)، ميزانيات شهرية لكل تصنيف (من الإعدادات)، سجل نشاط، تسوية الرصيد بسبب موثّق، تذكير صدقات موسمي، تذكّر آخر حساب مستخدم لتسريع الإدخال، وتصدير CSV بترميز يفتح في Excel بالعربية.

## حدود معروفة (للتطوير لاحقاً)
- أسعار الذهب يدوية بقصد (لا مصدر تلقائي غير موثوق). يمكن لاحقاً إضافة Edge Function تجلب سعراً من مصدر تعتمدونه وتكتب في `gold_prices`.
- الحسابات بعملة غير TRY تُعرض برصيدها لكنها لا تدخل في صافي الثروة (لا تحويل عملات).
- الإنشاء/التعديل دون اتصال مدعوم للعمليات المالية فقط؛ بقية الشاشات (حسابات، ديون…) تحتاج اتصالاً.
- التنبيهات داخل التطبيق (ليست إشعارات Push). يمكن إضافة Web Push لاحقاً.
